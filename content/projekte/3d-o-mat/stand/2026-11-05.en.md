---
titel: A note on your phone when the model is done
zusammenfassung: 3d-o-mat and img-o-mat can tell you through Onkel Bummel when a model or a picture is done; the first real try is still to come.
fertig:
  - Upload pictures and cut them out automatically
  - Have pictures checked by Gemma
  - Have pictures painted from an idea, with three image models to choose from
  - Turn them into a textured 3D model with TRELLIS.2, view it in the browser and download it as GLB
  - Add a skeleton, with test moves in the browser and as animations in the GLB
  - New versions install themselves as soon as no job is running
  - The interface in English, with a switch and the browser's language as the default
  - Colour scheme light, dark or following the system, selectable and remembered
  - Print file as 3MF or STL, watertight, with a base and a height you choose
  - Ready-made poses such as “Relaxed” or “Wave”, fine-tuning bones and fists by hand
  - Describe a pose, and Gemma poses the figure
  - Test moves with more punch, a closed fist when striking, a roundhouse kick and a fall with gravity
in_arbeit:
  - A message through [Onkel Bummel](/en/projekte/onkel-bummel/) when a model, a skeleton or a painted picture is done or fails, with a preview picture
  - Server messages and error texts in English too
geplant:
  - Colour print files for printers with several filaments
  - A warning about parts too thin to print
---

A 3D model takes ten minutes or more, and nobody wants to sit in front of the page that long. So 3d-o-mat and img-o-mat
now send a message through Onkel Bummel as soon as a job is done: for a model or a skeleton with the cut-out picture,
for painting with the pictures themselves. If something goes wrong, the message comes with a higher priority and says
why.

It is built and tested against a stand-in for Onkel Bummel. It is switched on with an entry in the settings; the first
try with the real Onkel Bummel is still to come, which is why it is still listed as in progress.
